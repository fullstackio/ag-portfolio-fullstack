## Architecture pivot — monorepo to single project (new, this session)

- **T040 — Dismantle the monorepo, rebuild as a single Next.js project.** **Done.** Removed `apps/`, `packages/`, `turbo.json`, `pnpm-workspace.yaml`'s `packages:` field. Moved all source into `src/` at the repo root: `apps/web/src/*` → `src/*` directly; `packages/ui`'s `button.tsx`/`utils.ts` → `src/components/ui/button.tsx`/`src/lib/utils.ts`; `apps/admin`'s route groups → `src/app/admin/(auth)/**` and `src/app/admin/(dashboard)/**`; admin's `sidebar.tsx`/`header.tsx` → `src/components/admin/*` (header renamed `AdminHeader` to avoid a naming collision); admin's `proxy.ts` → `src/proxy.ts` (kept the `proxy` export name and filename — a first attempt renamed this to `middleware.ts`/`middleware()` on the mistaken assumption that was the Next.js convention, but a production build warning revealed Next.js 16 renamed that convention from `middleware.ts` to `proxy.ts`, i.e. the original admin scaffold already had it right; matcher scoped from "everything except a few paths" to `/admin/:path*` specifically, since the public site must never require a token). Consolidated two near-duplicate `Providers` components into one (`src/components/providers.tsx`: QueryClient + ThemeProvider + Toaster). Consolidated two near-duplicate API clients into one (`src/lib/admin/api-client.ts`), dropping the unused public-site one. Single root `package.json`/`tsconfig.json`/`eslint.config.mjs` merging all three apps' dependencies and config. Verified: `pnpm type-check` and `pnpm lint` both pass clean; dev server serves `/`, `/admin/login`, and `/api/v1/health` (200, with a real MongoDB-backed health check) all from one process; screenshots confirm the public site and admin login render correctly post-move.
- **T041 — Replace NestJS API with Next.js Route Handlers.** **Done.** `apps/api/src/main.ts` + `app.module.ts` + `health/*` + `config/*` + `database/*` + `common/*` (NestJS bootstrap, ConfigModule, ThrottlerModule, DatabaseModule, HealthModule, exception filter, logging interceptor) replaced with: `src/lib/env.ts` (Zod, lazy-validated), `src/lib/mongodb.ts` (cached Mongoose connection), `src/lib/api-response.ts` + `src/types/api.ts` (consistent JSON response shape), `src/app/api/v1/health/route.ts` (GET handler checking Mongoose connection state + heap usage). Verified: `curl http://localhost:3000/api/v1/health` returns `{"success":true,"data":{"status":"ok","checks":{"mongodb":"up","memory_heap":"up"}}}` against a real local MongoDB. **Not replicated** (see Open questions / follow-ups): Swagger/OpenAPI docs, Throttler-equivalent rate limiting, a formal global exception-filter/logging-interceptor layer — basic security headers added via `next.config.ts` `headers()` as a partial substitute.
- **T042 — Update the BRD document itself for the new architecture.** **Done.** Added a new §0 "Architecture Decision Addendum" recording the pivot and its date/requester, and made targeted edits to §1 (Project Overview), §4.1 (In scope), §8 (component structure diagram), §9 (Admin Dashboard Requirements), §10 (Backend API Requirements), §11 (Technology Stack table), §12 (Repository Structure diagram), §13 (Docker and Infrastructure), §17 (Acceptance Criteria — dropped the Swagger bullet, updated the "apps run independently" bullet), and §18 (Implementation Phases). Functional/UI requirements (design fidelity, section content, typography, quality targets, living-doc rules) were left untouched since the pivot doesn't affect them.
- **T043 — Rewrite README for the single-project structure.** **Done.** Full rewrite: new architecture diagram, request-flow description, environment variable table, and command reference, replacing every `apps/web`/`apps/admin`/`apps/api`/Turborepo-filter reference.
- **T044 — Rewrite Docker setup for a single-app topology.** **Done, not live-tested.** New root `Dockerfile` (single multi-stage build, no Turborepo `prune`), `docker-compose.yml`/`docker-compose.prod.yml` collapsed from 4 services (mongo, api, web, admin) + nginx to 2 (mongo, app) + nginx, `docker/nginx/nginx.conf` collapsed from 3 upstreams to 1. **Follow-up:** actually run `docker compose up` to confirm — not done in this environment (no Docker available).
